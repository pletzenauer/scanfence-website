Массовая загрузка удобна, когда нужно много похожих кодов: по одному на стол, товар или филиал. Вы заполняете таблицу, сохраняете её в формате CSV и загружаете. ScanFence создаёт по одному коду на каждую строку.

> Массовую загрузку включает команда ScanFence. Если на странице QR Codes нет кнопки <kbd>Upload</kbd>, [напишите нам](mailto:hello@scanfence.com), и мы её включим.

## Пошагово

1. На странице **QR Codes** нажмите <kbd>Upload</kbd>.
2. Нажмите **Download sample CSV →**, чтобы получить файл `qr-codes-bulk-template.csv` с примерами строк.
3. Откройте его в Excel, Numbers или Google Sheets и заполните по одной строке на код. Первую строку (названия столбцов) оставьте без изменений.
4. Сохраните или экспортируйте файл в формате **CSV**.
5. Вернитесь в окно загрузки и выберите файл в блоке **Upload your CSV file**. Загрузка начнётся сразу после выбора.
6. В блоке **Upload results** будет видно, сколько кодов создано, а если какие-то строки не прошли — какие и почему.

## Столбцы

| Столбец | Обязательный | Что указать |
|---|---|---|
| `type` | Да | `standard` или `geofence` |
| `content` | Да | Ссылка или текст. Для динамических кодов — адрес назначения. |
| `name` | Нет | Отображаемое название, например *Table 12* |
| `category` | Нет | Название существующей категории |
| `tags` | Нет | Названия существующих тегов через `;` |
| `is_dynamic` | Нет | `true`, чтобы код был динамическим, иначе оставьте пустым или `false` |
| `global_scan_limit` | Нет | Число, например `100`. См. [Лимиты сканирований](/documentation/scan-limits/) |
| `limit_reached_url` | Нет | Куда переходят люди после достижения лимита |
| `geofence_lat` | Для геозоны | Широта, например `48.2082` |
| `geofence_lng` | Для геозоны | Долгота, например `16.3738` |
| `geofence_radius` | Нет | Радиус в метрах, от 50 до 5,000. По умолчанию 50 |

### Пример

```
name,type,category,content,is_dynamic,global_scan_limit,limit_reached_url,geofence_lat,geofence_lng,geofence_radius,tags
Table 1,geofence,Menus,https://example.com/menu,true,,,48.2082,16.3738,60,tables;indoor
Launch offer,standard,Marketing,https://example.com/offer,true,100,https://example.com/sold-out,,,,promo
```

## Советы

- **Сначала создайте категории и теги.** Несуществующие названия пропускаются, и код создаётся без них.
- **Координаты** можно узнать, нажав правой кнопкой мыши на нужную точку в Google Maps: первый пункт меню — *широта, долгота*.
- **Коды для нескольких мест** нельзя настроить через таблицу. Создайте их в приложении. См. [Коды для нескольких мест](/documentation/multi-location/).
- **Ошибки в строках** указывают номер строки, например *Row 4: Missing required fields (type or content)* или *Row 7: Geofence type requires valid geofence_lat and geofence_lng*. Исправьте эти строки и загрузите повторно только их: успешные строки уже созданы.
- Коды из массовой загрузки учитываются в лимите тарифа так же, как любые другие.
