title: Лимиты сканирований
description: Пропускайте только первые N сканирований («первым 100 — бесплатный кофе»), а всех остальных отправляйте на выбранную вами страницу.
---

Лимит сканирований (в приложении он называется **global scarcity limit**) считает каждое сканирование кода. Когда счётчик достигает лимита, все следующие люди попадают на **страницу достигнутого лимита** вместо обычного адреса назначения.

**Примеры:** первые 100 посетителей получают ваучер; розыгрыш завершается после 500 участников; ограниченная партия товара распродана.

## Лимит при создании кода

1. В окне **Generate a code** отметьте **Global scarcity limit**. По умолчанию лимит равен 50.
2. Введите **Total scan limit**.
3. Введите **Limit-reached URL**, например страницу «извините, всё закончилось».

## Задать или изменить лимит позже

На карточке кода блок **Scans & limits** показывает счётчик, например *Total 37 / 100*, с индикатором прогресса.

- Нажмите <kbd>Edit</kbd>, чтобы изменить **Global scan limit** (0 — без ограничений) и **Redirect URL when limit reached**, затем <kbd>Save changes</kbd>.
- Нажмите <kbd>Reset</kbd>, чтобы обнулить счётчик и начать новый круг. При этом обнуляются и счётчики правил кода.

## Полезно знать

- Если оставить URL для достигнутого лимита пустым, люди увидят короткое сообщение *This QR code has reached its scan limit*.
- Чтобы подсчёт был честным, повторные сканирования из одной сети учитываются не более 30 раз в час на один код. Эти дополнительные сканирования всё равно открывают страницу, просто не расходуют ваш лимит.
- У [кодов для нескольких мест](/documentation/multi-location/) можно задать отдельный лимит для каждого места.
