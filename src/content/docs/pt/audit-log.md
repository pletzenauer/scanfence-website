O registro de auditoria anota cada vez que alguém no seu espaço de trabalho cria, altera ou exclui algo: códigos QR, geocercas, membros da equipe e convites, assinaturas, categorias e tags. Use-o para responder "quem mudou o link do cardápio na sexta?" ou para mostrar a um auditor como seus códigos são gerenciados.

## Como ler a lista

Cada linha mostra **quando** aconteceu, **quem** fez, a **ação** (*Insert* para novo, *Update* para alterado, *Delete* para removido), a **tabela** afetada e um breve resumo, como *3 fields changed*.

**Clique em uma linha** para expandi-la. Você verá cada campo alterado com o valor antigo e o novo lado a lado.

## Encontrar um registro

- **Search** por usuário, tabela ou ação.
- **Action:** só inclusões, alterações ou exclusões.
- **Table:** só códigos QR, geocercas, perfis de usuário, convites da equipe, assinaturas, categorias ou tags.
- **From / To:** um período.
- **Clear filters** limpa tudo.

A página mostra os 500 eventos mais recentes que correspondem aos filtros. Refine os filtros para chegar aos mais antigos.

## Exportar

<kbd>Export CSV →</kbd> baixa os registros filtrados com data e hora, e-mail do usuário, ação, tabela, ID do registro e os dados antigos e novos.
