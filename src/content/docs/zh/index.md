用 ScanFence 制作的二维码只需印刷一次，就能一直掌控。一个二维码可以根据扫码的**地点**（地理围栏）、**时间**（时间规则）以及之前已有**多少人**扫过（扫描限额），把人引导到不同的页面。这些都可以随时更改，无需重新印刷。

## 应用概览

应用左侧的菜单包含以下部分：

| 部分 | 可以做什么 |
|---|---|
| **Dashboard** | 今日数据和最新扫描的实时动态。 |
| **Geofences** | 创建和编辑二维码所对照的区域。 |
| **QR Codes** | 创建、下载、编辑、筛选和删除二维码。 |
| **Analytics** | 扫描数据的地图、图表和 CSV 导出。 |
| **Team** | 邀请成员并管理他们的角色。 |
| **Audit Log** | 工作区内每一次更改的记录。 |
| **Support** | 联系方式和一对一帮助服务。 |
| **My Settings** | 套餐、账单、密码、标签和删除账户。 |

在菜单底部可以在深色主题（**Mission**）和浅色主题（**Instrument**）之间切换，也可以退出登录。在手机上，菜单收在顶栏的 ☰ 按钮后面。

> **注册前先试用。**[在线演示](/demo/app/)就是运行在示例数据上的真实应用。随便点什么都可以；不会保存任何内容，刷新后就会重置。

## 一分钟了解核心概念

- **静态还是动态。***静态*码直接包含你的链接：简单快捷，但永远无法更改，也不会被统计。*动态*码指向 ScanFence，再由它转发扫码者。正因如此，你才能之后修改跳转目标、统计扫描并添加规则。[了解更多](/documentation/create-qr-codes/#static-or-dynamic)
- **地理围栏**。地图上的一个圆，半径在 50 米到 5 公里之间。地理围栏码只对站在圆内的人有效。[了解更多](/documentation/geofences/)
- **工作区**。你创建的所有内容都属于你所在组织的工作区。你邀请的同事按各自的角色共享它。[了解更多](/documentation/team/)
