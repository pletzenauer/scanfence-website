## 1. Konto anlegen

1. Rufen Sie [app.scanfence.com/signup](https://app.scanfence.com/signup) auf.
2. Wählen Sie einen Tarif: **Basic**, **Starter** oder **Professional**. Oben wechseln Sie zwischen **Monthly** und **Annual**. Jährliche Abrechnung spart rund 17 %. Jeder Tarif beginnt mit einer 30-tägigen kostenlosen Testphase. Wenn Sie unsicher sind, welcher passt, lesen Sie [Tarife und Limits](/documentation/plans-and-limits/).
3. Geben Sie Ihre geschäftliche E-Mail-Adresse und ein Passwort (mindestens 6 Zeichen) ein, bestätigen Sie es und akzeptieren Sie die Datenschutzerklärung und die Nutzungsbedingungen.
4. Sie haben einen Gutschein? Geben Sie ihn unter **Voucher code** ein, bevor Sie fortfahren.
5. Klicken Sie auf **Create account & subscribe**. Sie werden zu unserem Zahlungsanbieter weitergeleitet, um Ihre Karte einzugeben, und danach zurück zur App.

> Werden Sie gebeten, zuerst Ihre E-Mail-Adresse zu bestätigen, klicken Sie auf den Link in der E-Mail und melden Sie sich an. Der Bestellvorgang wird dort fortgesetzt, wo Sie aufgehört haben.

## 2. Den ersten Code erstellen

1. Öffnen Sie im Menü **QR Codes** und klicken Sie auf <kbd>+ Generate QR</kbd>.
2. Lassen Sie den Typ auf **Standard**.
3. Geben Sie dem Code einen Namen, zum Beispiel *Schaufensterplakat*. Namen erscheinen in Listen, Auswertungen und Exporten.
4. Geben Sie unter **URL or text** die Webadresse ein, auf der Personen landen sollen.
5. Setzen Sie ein Häkchen bei **Make this a dynamic QR code**. Dann können Sie die Adresse später ohne Neudruck ändern.
6. Klicken Sie auf <kbd>Generate QR →</kbd>.

## 3. Testen und herunterladen

1. Ihr neuer Code erscheint als Karte oben in der Liste. Richten Sie die Kamera Ihres Smartphones auf den Bildschirm: Ihre Adresse sollte sich öffnen.
2. Klicken Sie auf <kbd>PNG</kbd> für ein Bild, das Sie in Dokumente einfügen können, oder auf <kbd>SVG</kbd> für den Druck. SVG bleibt in jeder Größe scharf. Senden Sie also diese Datei an Ihre Druckerei.
3. Nach einigen Scans zählt der Bereich **Scans & limits** auf der Karte mit, und <kbd>View analytics</kbd> zeigt, woher sie kamen.

## Wie es weitergeht

- Den Code nur an Ihrem Standort funktionieren lassen: [Geofences](/documentation/geofences/).
- Nachts oder am Wochenende eine andere Seite zeigen: [Zeitregeln](/documentation/time-based-rules/).
- Nur die ersten 100 Gutscheine vergeben: [Scan-Limits](/documentation/scan-limits/).
- Kolleginnen und Kollegen einbinden: [Team und Rollen](/documentation/team/).
